# Security

Do not open public issues with credentials, private KB material, authenticated
captures, or screenshots containing sensitive pixels. Rotate any exposed key
before reporting it.

The knowledge base has the same visibility as this Git repository. Keep a
private repository private if the vault will contain private notes.

Report vulnerabilities in this template through the Hraness repository's
[private vulnerability reporting](https://github.com/hraness/personal-monorepo-template/security/advisories/new)
with a minimal reproduction and no unrelated private data.

Private vulnerability reporting is a repository setting and may not carry
into a repository generated from this template. Before publishing a generated
repository, its owner should enable **Settings → Security → Private
vulnerability reporting** and replace the link above with that repository's
confidential reporting route.
