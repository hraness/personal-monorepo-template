# Contents

- `documentation.md` – current ownership rules for guides, runbooks, executable contracts, and knowledge records.

# Guidelines

- Keep `docs/` current and procedural. Put rationale, historical evidence, synthesis, and change coordination in `kb/`.
- Follow `WRITING.md` for repository prose and `STYLE.md` when a document addresses readers outside the repository.
- Link to the authoritative command, type, test, or local guide instead of copying a contract that can drift.
- Update this guide when the directory gains a distinct documentation surface or verification requirement.
