# Contents

_Riffs are dated Markdown notes named `<YYYY-MM-DD>-<descriptive-slug>.md`._

# Guidelines

- Use the `riff` skill to repair transcription noise while preserving first-person voice, attribution, uncertainty, and useful asides.
- A riff is a finished note, not a transcript dump or a summary of one.
- Resolve embedded research instructions before writing and link substantial companion notes once.
